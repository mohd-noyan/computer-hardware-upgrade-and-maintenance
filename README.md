# Computer Hardware Upgrade and Maintenance

## Project Role
IT Support Technician

## Project Overview
Performed desktop computer hardware maintenance and component inspection. Identified internal hardware components, handled memory modules, and removed the CPU cooling assembly to access motherboard components.

## Tasks Performed
Opened and inspected the desktop computer chassis. Identified motherboard components and connectors. Removed and examined RAM modules. Removed the CPU cooling assembly. Inspected the processor area and motherboard. Verified hardware installation and connections.

## Skills Demonstrated
Computer Hardware Support Desktop PC Maintenance RAM Installation and Replacement CPU Cooler Removal and Installation Motherboard Component Identification Hardware Troubleshooting Preventive Maintenance Technical Support

## Outcome
Successfully performed hardware inspection and maintenance procedures while following safe handling practices.
